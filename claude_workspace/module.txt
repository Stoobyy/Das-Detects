================================================================================
CRITICAL: CUSTOM KERAS LAYERS
================================================================================

When loading any saved model, you MUST pass custom_objects:

  from models.layers import DepthwiseSeparableConv2D, ConvBlock
  
  model = keras.models.load_model(
      model_path,
      custom_objects={
          'DepthwiseSeparableConv2D': DepthwiseSeparableConv2D,
          'ConvBlock': ConvBlock,
      }
  )

Without this, model loading will FAIL.

================================================================================
3-STEP TRAINING PIPELINE (Quick Reference)
================================================================================

Step 1: Create manifest
  python scripts/create_merged_manifest_custom.py

Step 2a: Extract MEL features (preferred)
  python scripts/prepare_mel_dataset_fast.py \
    --manifest D:\datasets\prepared\manifest_custom_balanced_v3.csv \
    --output D:\datasets\prepared_mel_custom_v3_rms \
    --opus-ratio 0.8

Step 2b: Extract LFCC features (alternative)
  python scripts/prepare_opus_dataset_fast.py \
    --manifest D:\datasets\prepared\manifest_custom_balanced_v3.csv \
    --output D:\datasets\prepared_opus_custom_v3_rms \
    --opus-ratio 0.8

Step 3: Train
  python scripts/train_from_features.py \
    --features <output_from_step2> \
    --output <model_output_dir>
