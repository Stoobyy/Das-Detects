7. MODEL ARCHITECTURE
================================================================================

Type: MobileNet-style Lightweight CNN (TensorFlow/Keras)
Input: (60, 79, 1) — 60 Mel bands × 79 time frames × 1 channel

  ConvBlock(16, 3×3, stride 2) → DWSepConv(32) + MaxPool → 
  DWSepConv(64) + MaxPool → DWSepConv(128) + MaxPool → 
  GlobalAvgPool → Dense(64) + ReLU6 + Dropout(0.3) → Dense(1, sigmoid)

Custom layers needed for loading:
  from models.layers import DepthwiseSeparableConv2D, ConvBlock

Model size: ~365KB, ~13k parameters

================================================================================
8. AUDIO & TRAINING CONFIG (config.py)
================================================================================

Audio: 16kHz, 2.5s window (40000 samples), RMS norm at -20dB
Features: N_FFT=512, HOP=160, WIN=400, N_MELS=60, TIME_FRAMES=79
Training: batch=32, epochs=50, lr=1e-3, label_smoothing=0.1
  Early stop patience=10, LR reduce patience=5 factor=0.5
Split: 70/20/10 train/val/test, seed=42

  import sys, os, numpy as np
  os.environ['TF_CPP_MIN_LOG_LEVEL'] = '2'
  sys.path.insert(0, r'C:\Users\amrit\OneDrive\Documents\GitHub\Das-Detects\claude_workspace')
  
  from tensorflow import keras
  from features import load_audio, pad_or_trim, normalize_audio, MelSpectrogramExtractor
  import config
  from models.layers import DepthwiseSeparableConv2D, ConvBlock
  
  model = keras.models.load_model(
      r'D:\datasets\models_mel_custom_v4\best_model.keras',
      custom_objects={
          'DepthwiseSeparableConv2D': DepthwiseSeparableConv2D,
          'ConvBlock': ConvBlock,
      }
  )
  extractor = MelSpectrogramExtractor()
  
  audio, _ = load_audio('path/to/file.wav', config.SAMPLE_RATE)
  audio = pad_or_trim(audio, config.AUDIO_SAMPLES)
  audio = normalize_audio(audio)
  features = extractor.extract(audio)
  features = np.expand_dims(features, axis=0)
  
  prob = model.predict(features, verbose=0)[0][0]
  score = prob * 100
  # 0-40: Human | 40-70: Suspicious | 70-100: AI
